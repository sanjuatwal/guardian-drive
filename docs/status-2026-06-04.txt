DECISION 1: Hardware Abstraction Layer (HAL) from day 1
  - Business logic talks to interfaces, never hardware directly
  - Swapping MPU-6050 -> ICM-42688-P = rewrite one driver file only
  - Agreed: prototype and production use same logic, minimal change to switch

DECISION 2: Prototype hardware is DEV only (not shipped to customers)
  - MPU-6050, breadboard, TP4056 = bench testing only
  - Production parts (ICM-42688-P, NEO-M9N, BG95-M3, BQ24074) ordered for
    real car testing and manufacturing
  - Production BOM locked in hardware/BOM.md

DECISION 3: Glass break / microphone removed from MVP
  - INMP441 mic arriving June 15-25 but will NOT be wired for MVP
  - Glass break = Nice to Have, post V1.5
  - No firmware work for audio detection until after V1.5 ships

DECISION 4: CAN bus approach corrected
  - Use ESP32 built-in TWAI + SN65HVD230 CAN transceiver
  - NOT MCP2515 (5V logic, wrong for ESP32-S3)
  - Simpler wiring, no SPI overhead, no level shifter needed

DECISION 5: Power management corrected
  - BQ24074 power-path charger for all car-connected testing and production
  - TP4056 acceptable for bench current measurements only
  - Target battery: 5000-7000mAh (measure actual draw in Week 4 first)
