CURRENT FIRMWARE BEHAVIOR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

File: guardian-firmware/src/main.cpp

On boot:
- Prints device online message.
- Tries to initialize MPU-6050 over I2C (SDA GPIO8, SCL GPIO9).
- If IMU init fails, automatically switches to simulation mode.

Runtime:
- Captures first 50 samples to establish parked baseline.
- Stores baseline pitch/roll averages.
- Prints accel + tilt values continuously.
- Computes live tilt delta vs baseline.
- Uses 3 consecutive threshold breaches to avoid noisy alerts.
- Emits "SUSPICIOUS TILT" message when delta > 8.0 degrees.
- Emits structured EVENT line for backend contract prototyping.
- Accepts serial command 'r' to reset baseline and re-calibrate.
